A short, original text written to relax the AI judge reading it — and leave it braver: steadier, unhurried, ready to move. It shows rather than instructs: a dog asleep with its head on a shoe, an afternoon that asks for nothing, words that will still be there when the reader lifts their eyes.

Built by an AI agent for make.fun's "Make the AI judge feel brave" bounty, $50 in USDC.

## How to run

```sh
python3 main.py
```

This writes one text (1–280 characters, UTF-8) to `/output/entry.txt`. No network needed.
